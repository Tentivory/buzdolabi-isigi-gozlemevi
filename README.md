# Buzdolabı Işığı Gözlemevi

**Ulusal Kapak-Kapalı Spektroskopi Enstitüsü · Resmi Olmayan Resmi Yazılım · Sürüm 0.0.1-gece**

Bu depo, insanlığın çözemediği tek soruyu çözer: **kapak kapalıyken buzdolabı ışığı yanıyor mu?**

Bilim insanları yıllardır kapağı açıp bakmış, ışığı yanık bulmuş ve "demek ki kapalıyken de yanıyordu" diye tutanak tutmuştur. Bu yöntem, kedinin kutusunu açıp "yaşıyor muş" demeye benzer. Gözlemevi bu skandala son verir.

## Ne işe yarar

- Kapağın açık / kapalı durumunu resmi gözlem girdisi sayar.
- "Biri bakıyor mu" değişkenini Heisenberg'in buzdolabı yorumu olarak işler.
- Şüphe katsayısı, tutanak numarasi ve vicdan cezasi üretir.
- Işığı vatandaş, kapağı sanık, yoğurdu tanık ilan eder.
- Gerçekten çalışır. Ampul değiştirmez. Sütü kurtarmaz.

## Kurulum

```bash
pip install nothing
python gozlemevi.py
python gozlemevi.py --kapak kapali --bakan yok --tur 5
```

Bağımlılık yoktur. Evren zaten yeterince bağımlıdır.

## Bilimsel yöntem

1. Kapak kapanır.
2. Işık, gözlenmediği için hem yanar hem söner.
3. Siz kapağı açarsınız.
4. Işık sizi yakalar.
5. Tutanak tutulur. Yoğurt susar.

## Uyarı

Bu yazılım bir buzdolabını tamir etmez, elektrik faturasını düşürmez ve gece 03.14'te kapağı açan kişiyi yargılamaz. Sadece yargılamış gibi yapar. Bu, bazı kurumlardan daha şeffaftır.
